# 時系列画像作成ツール

連続フレームの指定した横位置から縦の帯を切り出し、時間順に並べた画像を作成します。通常版、目盛り付き画像、参照点を利用した上下の揺れ補正、一括処理用のスクリプトを含みます。

## セットアップ・実行

Python 3.12以上を用意し、`python -m pip install -r requirements.txt` を実行します。

`python make_spacetime_image.py "画像フォルダー" --x 1352 --output "spacetime.png" --annotated-output "spacetime_axes.png" --fps 240 --pixels-per-cm 93.4`

位置・fps・縮尺は例です。撮影条件に合わせて変更してください。基本スクリプトは画像合成用で、揺れ補正には別のスクリプトを使用します。各スクリプトの `--help` を参照してください。

動画・フレーム画像・解析結果は同梱しません。研究用の一括処理スクリプトには元データの保存パスが含まれるため、使用時に変更してください。
